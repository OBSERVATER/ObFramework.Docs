# Framework API reference

Generated from checked-in C# declarations. Use the [project guide](../README.md) for setup and usage.

Public and protected declarations (including implicit interface members and enum values) are grouped by source folder. Inherited members, compiler-synthesized members and generated business members are not expanded. This is a source inventory, not a compiled ABI or a promise that every engine project builds standalone. Unity editor symbols are enabled; other conditional branches may be absent. Attributes and generic constraints are retained; method bodies and nonconstant field initializers are omitted. Private accessors remain visible as part of property signatures.
